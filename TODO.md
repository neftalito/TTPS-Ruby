# Trabajo Final - Ruby

## Deberán implementar un módulo de reportes de ventas con visualización gráfica para acceder a una mejora en la nota.

**Objetivo:** Incorporar un módulo que permita analizar las ventas del sistema mediante métricas y gráficos, utilizando los datos reales registrados.

---

## Funcionalidades requeridas

El módulo de reportes deberá incluir:

### Métricas obligatorias
- Total recaudado en un período
- Cantidad de ventas realizadas
- Promedio de importe por venta
- Cantidad de productos vendidos

### Análisis de ventas
- Ventas por tipo de producto (CD / Vinilo)
- Ventas por género musical
- Top 5 productos más vendidos

### Filtros obligatorios
El usuario debe poder filtrar los reportes por:
- Fecha desde / hasta
- Tipo de producto
- Género
- *(Opcional recomendado)* empleado que realizó la venta

---

## Consideraciones importantes
- No deben incluirse ventas canceladas en los cálculos
- Los datos deben provenir exclusivamente del sistema desarrollado
- Debe existir una sección de reportes separada de la gestión de ventas
- Los gráficos deben ser claros, legibles y correctamente rotulados
- Se deben mostrar tanto valores numéricos como visuales

---

## Requisitos de entrega
- Datos de prueba (seed) que permitan visualizar correctamente los reportes
- README explicando:
  - Cómo acceder al módulo
  - Qué métricas se muestran
  - Cómo generar datos de prueba
